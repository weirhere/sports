## Decision

**The player page's Profile card gets a Born row.** ESPN's athlete payload
has carried `displayBirthPlace` all along. It is now decoded
(`ProfileAthleteDTO`, `transformAthleteProfile`), merged door-first, and
rendered right after Age or Class: Height · Weight · Age · Born · Position ·
College · Jersey.

## Why

The 2026-09-20 spec asked for "hometown", and the field had no confirmed
source until the 2026-11-02 college probe found it. The label is "Born" and
not "Hometown" (Andy, COR-150) because the field is a birthplace, which for
a lot of pros isn't where they grew up, and the coach page already labels
the same ESPN field "Born". With the source confirmed, the spec's `?`
marker for an unproven field isn't needed.

## Web parity

shipped — same row, same position, same label in `web/src/lib/player-profile.ts`.
