## Decision

**Trophies read the pro leagues' postseason headlines as ESPN actually prints them.** A trailing " - Game N" comes off a headline before it is matched. The NBA's and NHL's conference round takes a canonical name per league ("Eastern Conference Finals", "Western Conference Final", which reads "Western Conference Finals" at two or more) whichever way the wire spells it. The 2023 "NBA In-Season Tournament Championship" counts as the NBA Cup. `ProPostseasonHeadlines` pins the probed strings verbatim.

## Why

E15 called the pro wording reasoned rather than seen, and a live probe of every pro league's postseason from 2014 to 2025 found it wrong in three places. Every series game carries its number, so the NHL title's round test read "6" and no Stanley Cup was ever derived. The current conference-round spelling ("East Finals", "West Final") has no "Conference" in it. The 2010s spelling kept the game number in the trophy's name, which made each game won in a conference final a row of its own. The name is canonical rather than ESPN's because the wire changed spelling mid-window, and a franchise with titles on both sides of the change would otherwise show two rows of one trophy.
