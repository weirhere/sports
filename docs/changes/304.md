## Decision

**A followed college basketball conference starts open on Scores.** The college basketball conferences that start closed (2026-11-02) are now only the ones nobody follows. A followed conference, hoisted under Following, opens like the rest of what's yours. `UIStateStore`'s default takes the section's followed state (`GameSection` overloads of `isExpanded`, `toggle`, `collapseAll`, `expandAll`). While the conference is followed, its open or closed state lives in `collapsedDays`, and after an unfollow it falls back to `expandedSections`.

## Why

The closed default exists so a weeknight isn't seven hundred rows. A followed conference is one section the fan asked for, not hundreds, and a closed card at the top of the page reads as nothing on tonight. The rule read the section id alone, so it couldn't tell the two apart.

## Web parity

shipped — `startsClosed` takes the section and spares a followed one.
