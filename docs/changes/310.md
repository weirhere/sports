## Decision

**The NBA's titles go all-time, and they follow the franchise.** `TrophyRegistry` gets the NBA's verified list, `nbaChampionships` (in `TrophyRegistry+NBA.swift`): the 1946–47 through 2013–14 seasons, 67 champions. It uses the derived path's own "NBA Finals" kind, so the wire's 2014–15 on lands on the same row. The three BAA seasons are in. Relocated titles stay with the franchise: Minneapolis to the Lakers, Rochester to the Kings, Syracuse to the 76ers, Philadelphia's Warriors to Golden State, St. Louis to the Hawks, the 1978 Bullets to the Wizards and Seattle's 1979 SuperSonics to the Thunder. 1947–48 has no row, because the original Baltimore Bullets have no successor. The list carries no `source`. The Celtics' shelf reads 18 and the Lakers' 17.

## Why

This applies COR-94's third call (Andy, 2026-11-04), including the note there that the SuperSonics' 1979 title goes to the Thunder's id because the NBA credits it to the franchise. The BAA seasons count because the NBA counts them as its own championships, the same reasoning that let #309 count the NFL's standings-decided seasons. No selector choice changes any current team's count, so the trophy is its own source and needs no caption line. Every ESPN id is resolved in the tests from an abbreviation in the captured `nba-standings` fixture, so a mistyped id fails as a wrong total. The 17 franchise totals sum to 67, so a dropped, doubled or misfiled season moves at least one of them.
