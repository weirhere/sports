## Decision

**The App Store frames carry real team, league and conference marks again, and the capture suite's gray-disc mode stays as the default and the fallback.** `AppStoreScreenshots` still launches with `-screenshot.neutralLogos YES` unless `TEST_RUNNER_SCREENSHOT_NEUTRAL_LOGOS=NO` is passed; the 2.9.0 set was shot with it off. The listing's § 2.9.0: reshot records the risk.

## Why

Andy, 2026-10-19, during the reshoot: "they can be the actual logos." The second 4.1(a) rejection (2026-09-29) was for exactly these marks in the frames, so the call is his to make and the record says it was made knowingly; the gray-disc path is one environment knob away if it bounces, and no `as-*.html` source would change. The suite's default stays neutral so a future run that forgets the knob errs on the side that cleared review.
